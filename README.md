This data derives from the written work "An Historical Account of the Black Empire of Hayti" by Marcus Rainsford. Rainsford was a soldier who served the British Army in the British West Indies. Rainsford documented his personal firsthand account of the Haitian Revolution. In this document, Rainsford highlights the deeds of the Revolutionary leader Toussaint Louverture and the French colonial brutality. In addition, he challenges the negative, racist narratives Europeans held of the black-slave revolt. This dataset represents the historical account of a White, British sympathizer towards the Haitian Revolution. However, this dataset is not free from the patriarchal norms of the late 18th century. In his historical account, Rainsford only mentions women when it relates to a male's standing or as a form of evidence of French brutality. Though he does praise the female population of Haiti, subverting common European narratives, it is an overgeneralization of the victimization and glorification of Haitian women, ignoring wartime contributions such as engaging in combat and aiding in nursing. A row represents a sample from Rainsford's text that contains information about women and how Rainsford viewed them during this revolutionary period. This coding project is done to create a findable dataset documenting how women are portrayed in this primary historical source. I seek to establish a DOI for this data, so it may become a searchable resource for humans and computers alike. I seek to make this dataset also accessible. This will be achieved by posting my project to GitHub as a public file for easy access. The project has been created using HTTP for easy retrieval and PANDAS to visualize the data into rows. This data will also be interoperable. Due to its nature of being a csv file, it can be read in other applications and workflows as rows, its actual text content, and a combination of the two. The dataset uploaded to GitHub also enables code to be exchanged and integrated across machines for data interpretation. For this data to be reusable in future projects, I have detailed the origin of my text data from Marcus Rainsford’s “An Historical Account of the Black Empire of Hayti” in addition to detailing the origins of this code in the terminal, using HTTP format, Python, and PANDAS. In all, my project seeks to achieve the FAIR principles as modeled by the Data Descriptors in Scientific Data in order for this project to be of use to the general public and the world of Caribbean academia.
